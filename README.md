# 3D Printing Cost Engine

This is another highly theoretical project. I built it as a pricing tool for long term 3D printing runs. It lets you make all the necessary variable adjustments to figure out exactly how much a print costs and how you should price it.

## Features
- **Material Costs:** Calculates exact cost based on filament weight and spool price.
- **Machine & Power:** Factors in electricity rates, printer power consumption, and machine depreciation over its lifespan.
- **Labor:** Accounts for prep and post-processing time.
- **Profit Strategy:** Adjust your markup percentage to generate a final retail price and see your exact profit margin.
- **Dark Theme:** Sleek, modern UI that works perfectly in the browser.
